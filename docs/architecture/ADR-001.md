# ADR-001 — Static Frontend Architecture

## Status

Accepted

## Date

2026-09-18

## Requirement Addressed

- REQ-AZ-001
- REQ-AZ-002
- REQ-AZ-003
- REQ-AZ-004

## Decision

Use a static frontend implemented with HTML, CSS, and JavaScript and host it using Azure Storage static website hosting.

## Alternatives Considered

### React/Vite

Rejected for this project because the approved requirements explicitly call for HTML, CSS, and JavaScript and do not require a frontend framework.

### Static hosting outside Azure

Rejected because Azure Storage is an explicit requirement.

### Server-rendered application

Rejected because the approved product does not require server-side page rendering.

## Trade-offs

Advantages:

- Directly satisfies the frontend technology requirement.
- Simple deployment model.
- Minimal runtime complexity.
- Low operating cost.
- Clear evidence of web fundamentals.

Trade-offs:

- Less component abstraction than a frontend framework.
- More manual HTML/CSS organization.

## Consequences

The frontend remains a static artifact.

Dynamic visitor-count behavior is isolated to JavaScript calling the backend API.

No frontend framework is introduced.
