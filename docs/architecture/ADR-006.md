# ADR-006 — HTTPS/CDN Delivery Architecture

## Status

Accepted

## Requirement Addressed

- REQ-AZ-005
- REQ-AZ-006
- REQ-AZ-014
- REQ-AZ-015
- REQ-AZ-SEC-004

## Problem

The project requires:

- Azure Storage static website hosting.
- Public HTTPS.
- CDN/delivery capability.
- A public hostname.
- A numeric recurring cost ceiling.

The Azure-native delivery options available for new deployments do not satisfy the project's cost constraint:

- Azure Front Door Standard is rejected because its current base fee is US$35/month before usage charges.
- Azure CDN from Microsoft (classic) is rejected because new profiles/domains are no longer available and the service is on the retirement path.

## Decision

Use:

```text
Public Hostname
      |
      v
Cloudflare Free proxy/CDN
      |
      v
Azure Storage Static Website
```

Cloudflare Free is the selected delivery layer because its Free plan provides CDN, DNS, and Universal SSL without a recurring plan charge. The Azure Storage static website remains the required origin/runtime host.

The selected delivery path is therefore **not an Azure CDN service**.

## Alternatives Rejected

### Azure Front Door Standard — Rejected

Rejected for the MVP because the current Standard tier has a US$35/month base fee before variable usage charges. This does not fit the approved project cost ceiling.

### Azure CDN from Microsoft (classic) — Rejected

Rejected because Microsoft no longer permits new profile creation or new domain onboarding for the classic service, and the service is on the retirement path.

## Cost Decision

OR-003 is resolved with the following measurable MVP ceiling:

- **Recurring cloud/service cost ceiling: US$5/month.**
- **Planned one-time domain registration cost: US$0.**
- The MVP uses the existing free-hostname/subdomain direction and does not require paid domain registration.
- Any future paid domain or service outside this ceiling requires an explicit project decision before adoption.

Cloudflare Free contributes US$0/month to the recurring ceiling. Azure Storage and the required serverless backend remain subject to actual usage-based charges and must remain within the US$5/month project ceiling.

## DNS / Hostname Compatibility

The project retains the approved FreeDNS/afraid.org hosted-hostname interpretation from OR-002.

The delivery architecture requires the final hostname to be compatible with Cloudflare proxying and HTTPS. FreeDNS supports CNAME and NS records, including delegation of a hostname to another nameserver; the actual selected hostname must be verified during implementation.

This is a **verification condition**, not an open architecture decision:

- OR-002 remains resolved as the public-hostname interpretation.
- OR-003 is resolved by the numeric ceiling above.
- OR-004 is resolved by this ADR.
- Final acceptance still requires successful hostname compatibility verification.

## Deviation

The original challenge recommends Azure CDN for HTTPS. This project explicitly deviates from that implementation detail:

> **Delivery/CDN provider: Cloudflare Free, not Azure CDN.**

The project still preserves the required functional outcomes:

- Azure Storage static website hosting.
- Public HTTPS.
- CDN/delivery capability.
- Public hostname.
- Source-controlled deployment.
- Cost-controlled delivery.

The project documentation must not claim that Azure CDN is used.

## Consequences

### Positive

- Avoids the US$35/month Azure Front Door Standard base fee.
- Avoids dependence on Azure CDN classic, which is no longer available for new profiles/domains.
- Keeps Azure Storage as the required static website origin.
- Provides HTTPS and CDN/proxy delivery through a zero-recurring-cost delivery plan.
- Keeps the delivery architecture compatible with the project's cost-first constraint.

### Negative

- The CDN/delivery layer is no longer Azure-native.
- Cloudflare becomes an additional external service dependency.
- Hostname delegation/proxy compatibility must be verified before production acceptance.
- Frontend CI/CD must invalidate or otherwise account for Cloudflare caching rather than an Azure CDN endpoint.

## Freeze Gate

**Resolved subject to hostname compatibility verification.**

Before production delivery is accepted, verify:

1. The approved FreeDNS hostname can be delegated/configured for Cloudflare.
2. Cloudflare can proxy the hostname to the Azure Storage static website origin.
3. Cloudflare Universal SSL provides valid HTTPS for the final public hostname.
4. The final hostname resolves publicly and serves the resume successfully.
5. The measured recurring project cost remains within the US$5/month ceiling.
